Features

Set it up once, then forget it.

⚡

Automatic login

On joining Wi-Fi, coming back into range, waking from sleep, and when the 24-hour session expires.

🔐

Password in Keychain

Enter your username and password once. They're stored in your Mac's Keychain, and you can change them anytime in Settings.

🔔

Tells you when you're out

Get a notification if you're not logged in or the portal rejects your password. Once per problem, never spammy.

📍

Only on BHU-WiFi

At home, at a café or on a hotspot it stays completely idle. Your password only ever goes to the BHU login portal.

🛡️

Lockout protection

If the portal rejects your password, auto-login pauses instead of hammering it, until you update the password.

🔄

Refresh, log in, log out

Logged in from a browser? Refresh shows it instantly. Need to sign out? One click.

Setup

Up and running in a minute.

  1. Install

    Paste the install command above into Terminal. A 🎓 appears in your menu bar.

  2. Add your account

    Type your BHU Wi-Fi username and password in the Settings window and click Save.

  3. Allow Location

    macOS only shares the Wi-Fi name with apps that have Location access. Your location is never used.

  4. Turn on Open at Login

    In Settings, so it starts with your Mac. Done!

Tip: in System Settings → Wi-Fi → (i) next to BHU-WiFi, set Private Wi-Fi Address to Off so the portal recognises your Mac between reconnects.

FAQ

Questions

Is my password safe?

It's stored in your Mac's Keychain, the same place Safari keeps your passwords. The app only sends it to the BHU login portal, and only after checking that you're on BHU-WiFi and that the login page really is BHU's. The full source code is on GitHub for anyone to check.

Why does it ask for Location?

Since macOS Sonoma, apps can only read the name of the Wi-Fi network you're on if they have Location access. BHU WiFi uses it purely to stay idle on every network except BHU-WiFi. It never reads or stores your location.

macOS says it "can't verify the developer"

The app isn't notarized by Apple (that needs a paid developer account). The install command handles this for you. If you downloaded the .zip by hand, open System Settings → Privacy & Security, scroll down and click Open Anyway.

I don't see the 🎓 icon

On MacBooks with a notch, menu bar icons can hide behind it when the bar is full. Quit a few other menu bar apps, or hold ⌘ and drag icons around to make room.

It asks for Keychain or Location access again after an update

That's expected for apps that aren't signed with an Apple Developer ID. Click Always Allow for Keychain and allow Location again.

How do I update or uninstall?

To update, run the install command again. To uninstall, quit the app from the 🎓 menu and run:

rm -rf "/Applications/BHU WiFi.app" ~/Applications/"BHU WiFi.app"
rm -f ~/Library/Logs/bhu-wifi-login.log
defaults delete io.github.sarthak090.bhu-wifi
security delete-generic-password -s "BHU WiFi Login"
Something isn't working

Open 🎓 → Open Log to see what happened, then open an issue with the relevant lines. Please never paste your password.
